# Plan to Separate Dog Tinder and Dog Adoption Features

## 1. Dog Tinder Feature (using `dogs` table)

*   **Controller:** `app/Http/Controllers/DogTinderController.php` seems to be correctly implemented and using the `Dog` model. No changes are needed here for now.
*   **Model:** `app/Models/Dog.php` will be used for this feature.
*   **Routes:** The routes in `routes/web.php` for dog tinder are correctly pointing to `DogTinderController`.

## 2. Dog Adoption Feature (using `shelter_dogs` table)

This feature requires more changes to use the `shelter_dogs` table and be restricted to shelter users.

### 2.1. Update Controller: `DogAdoptionController.php`

*   Modify `app/Http/Controllers/DogAdoptionController.php` to use the `ShelterDog` model instead of the `Dog` model.
*   Update the `index` method to fetch `ShelterDog` records.
*   Update the `show` method to accept a `ShelterDog` instance.
*   Update the `adopt` method to create an `AdoptionApplication` for a `ShelterDog`.

### 2.2. Update Routes: `web.php`

*   The routes for adoption are currently using `/dogs`. It would be better to change them to `/shelter-dogs` to reflect the new structure.
*   Update the routes in `routes/web.php` to point to the updated methods in `DogAdoptionController` and use the `shelter-dog` parameter.

### 2.3. Update Views

*   The view `resources/views/user/adoptions/adoption-gallery.blade.php` should be updated to display `ShelterDog` data.
*   The `ShelterController`'s `adoptionGallery` method should pass the `ShelterDog` data to this view.

### 2.4. Shelter User Role

*   Ensure that only users with the 'shelter' role can add/manage `ShelterDog` records. This will likely involve creating a new controller or modifying the existing `ShelterController` to handle CRUD operations for `ShelterDog` and protecting those routes with middleware.

## 3. Implementation Steps

1.  **Modify `DogAdoptionController.php`:** Change all instances of `Dog` to `ShelterDog`.
2.  **Modify `routes/web.php`:** Update the adoption routes.
3.  **Modify `ShelterController.php`:** Implement the `adoptionGallery` method to fetch and display `ShelterDog` records.
4.  **Modify `adoption-gallery.blade.php`:** Update the view to correctly display the `ShelterDog` information.
5.  **Create Shelter Dog Management:** Create a new controller and routes for shelters to manage their dogs, protected by the `shelter` role middleware.
